# 📊 End-to-End Data Analytics Project

**Turning 65,000+ raw records into meaningful business insights using Python, SQL Server, and Power BI.**

---

## 🔄 Project Pipeline

**Business Requirements → Data Cleaning → Exploratory Data Analysis → SQL Server → Power BI Dashboard**

---

## 📌 Project Overview

This project follows a real-world data analytics workflow, starting with business requirement analysis and ending with an interactive Power BI dashboard.

The goal was to transform raw data into reliable, structured information and generate meaningful insights aligned with business objectives.

## 🎯 What I Did

### 01. Business Requirements Analysis
- Created a Business Requirements Document (BRD).
- Defined business objectives, KPIs, and key analytical questions.
- Established analysis requirements and dashboard expectations.

### 02. Data Cleaning & Preprocessing
- Processed approximately **65,000 records**.
- Handled missing values and duplicate records.
- Corrected data types and inconsistent values.
- Standardized columns and prepared the final dataset.

### 03. Exploratory Data Analysis
- Performed EDA using Python.
- Analyzed business trends, patterns, and distributions.
- Evaluated KPIs and answered BRD-defined questions.
- Extracted actionable insights from the data.

### 04. SQL Server
- Imported the cleaned dataset into Microsoft SQL Server.
- Created database tables.
- Executed SQL queries for data retrieval and validation.
- Connected SQL Server with Power BI.

### 05. Power BI Dashboard
- Built an interactive dashboard using the SQL Server data.
- Created KPI cards and analytical visualizations.
- Implemented filters and slicers.
- Presented business insights through interactive reports.
